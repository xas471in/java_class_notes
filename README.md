## How to use these notes

- Read one section at a time.
- Type the example yourself instead of only reading it.
- Guess the output before running the program.
- Try the questions before opening the hints.
- If your program fails, read the error and check one thing at a time.
- Explain your solution in your own words.

## Visual learning

The chapters include small diagrams and code walkthroughs that render directly on GitHub. More visual examples can be added as the lessons grow.
