# Java Class 10 — Learning Guides

A step-by-step collection of Java notes, examples, practice questions and progressive hints.

## Suggested learning order

1. `01-java-program-structure.md` — Program skeleton, main method and output
2. `02-variables.md` — Variables and data types
3. `03-user-input-scanner.md` — Keyboard input
4. `04-calculations-and-math.md` — Arithmetic and Math methods
5. `05-decision-making.md` — Conditions and logical operators
6. `06-switch-menu-driven-programs.md` — Switch and menus
7. `07-loops.md` — For, while and do-while
8. `08-number-breakdown-algorithms.md` — Digits, palindrome and Armstrong numbers
9. `09-nested-loops-patterns.md` — Nested loops and patterns
10. `10-arrays.md` — Single-dimensional arrays
11. `11-strings-and-characters.md` — Text and character processing
12. `12-methods-functions.md` — Methods, parameters and return values
13. `13-classes-and-objects.md` — Introduction to OOP
14. `14-constructors-and-this.md` — Constructors and `this`

## How to study

- Run every example yourself.
- Attempt the questions before opening the hints.
- Use Tip 1, then Tip 2, then Tip 3 only if needed.
- Test edge cases and explain the logic in your own words.
- Check your school's board syllabus before teaching enrichment topics.
